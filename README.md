### Como penso as ferramentas

Três regras que valem para tudo que publico aqui:

**Roda local.** Nenhuma ferramenta minha envia o seu código ou os seus dados para lugar nenhum. O que a ferramenta lê está documentado, e o que ela não lê também.

**Diz o que não faz.** Nenhuma delas vai prometer detectar código gerado por IA, porque não existe método confiável para isso. As limitações ficam no README e dentro do próprio relatório, não no rodapé.

**É auditável.** Arquivo único, biblioteca padrão, sem dependências. Você consegue ler o que ela faz antes de rodar.
